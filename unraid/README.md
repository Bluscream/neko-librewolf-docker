# Unraid template

`neko-librewolf.xml`: Docker → Add Container → Template → paste the raw URL
`https://raw.githubusercontent.com/Bluscream/neko-librewolf-docker/master/unraid/neko-librewolf.xml`,
or copy it to `/boot/config/plugins/dockerMan/templates-user/my-neko-librewolf.xml`.
Settings and env vars: [apps/librewolf/README.md](../apps/librewolf/README.md).
